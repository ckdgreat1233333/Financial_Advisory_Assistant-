Instructions

Extract only information that explicitly appears in the document.

Identify the following where available:

- Claimant Name
- Policy Number
- Claim Type
- Incident Date
- Incident Location
- Claimed Amount
- Loss Description
- Cause of Loss
- Reported / Estimated Amount
- Coverage Limit
- Policy Inception Date
- Prior Claims
- Diagnosis
- Treatment Cost
- Vehicle Registration
- Property Address
- Police Report / FIR Number

Also identify:

- Missing required information
- Invalid or inconsistent information
- Possible OCR errors
- Suspicious or unreadable sections

Never guess missing values.

Return only factual information found in the document.
